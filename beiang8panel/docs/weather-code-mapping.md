# 和风天气代码（condition.code）对照表

> 供 `GET /getWeather` 返回的 `weathercode` 字段（数字）与天气现象文本对应，用于前端按语言（中/英/日…）本地化展示天气。

## 权威来源

| 内容 | 链接 |
|------|------|
| 天气现象对照表（本文档数据来源） | https://dev.qweather.com/docs/resource/weather-conditions/ |
| 英文版 | https://dev.qweather.com/en/docs/api/weather/weather-conditions/ |
| 每日天气预报（含 150~153 夜间码说明） | https://dev.qweather.com/docs/api/weather/weather-daily-forecast/ |

官方提供 `weather-conditions.csv` 可直接下载用于构建前端映射表；官方声明天气现象代码会**新增/修改/删除**，前端映射表查不到时应回退到接口的 `weather` 文本字段（见 [HTTP_API.md](HTTP_API.md) 的 `/getWeather` 说明）。

## 夜间代码（每日预报 days[].day / days[].night）

实时天气接口（current）不会返回夜间码，仅**每日预报**的 `day`/`night` 对象出现：

| 代码 | 文本 |
|:---:|---|
| 150 | 晴（夜间） |
| 151 | 多云（夜间） |
| 152 | 少云（夜间） |
| 153 | 晴间多云（夜间） |

## 使用约定（后端）

- 后端 `/getWeather` 透传 `weathercode`（number）。解析失败默认 `0`，前端按"查不到"处理，回退用 `weather` 中文文本。
- `999` 为和风"未知"码，同样按查不到处理。
