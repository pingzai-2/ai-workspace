### 1.1. 开机流程设置

1. **1001H 新风模块开启**：设置为1
2. **1002H 超净模式开启**：设置为1
3. **1003H 调湿模块开启**：设置为1

> 注：开启任何一个模块时，1000H会被自动开启。

### 1.2. 关机流程设置

1. **1001H 新风模块关闭**：设置为0
2. **1002H 超净模式关闭**：设置为0
3. **1003H 调湿模块关闭**：设置为0

或直接**1000H 整机关机**：设置为0，则1001H、1002H、1003H均自动为0

> 注：三个模块全部关闭时1000H会被关闭。

## 2. 通信协议

设备采用Modbus规约RTU模式，可以方便地与多种组态软件相连接。

### 2.1. 通讯参数

| 参数 | 设置值 |
| :--- | :--- |
| Modbus通讯模式 | RTU模式 |
| 波特率 | 9600 |
| 奇偶校验 | 无校验 |
| 停止位 | 1位 |
| 设备初始地址 | 4CP: 209(D1H)；全热新风: 193(C1H) |
| 通讯命令间隔时间 | ≥250毫秒 |
| 超时时间 | 50ms |

### 2.2. 通讯数据格式

通讯时每个寄存器数据以字（2字节）的形式回送，回送的每个字中，高字节在前，低字节在后。

### 2.3. 帧格式

支持功能码：**03H、06H、10H、04H、02H**

## 4. 参考源程序

### 4.1. CRC校验程序

```c
// CRC16 校验
unsigned short CRC16_CACU(unsigned char *arr_buff, unsigned char len)
{
    unsigned short crc = 0xFFFF;
    unsigned char i, j;

    for(j = 0; j < len; j++)
    {
        crc = crc ^ (*arr_buff++);
        for(i = 0; i < 8; i++)
        {
            if((crc & 0x0001) > 0)
            {
                crc = crc >> 1;
                crc = crc ^ 0xa001;
            }
            else
            {
                crc = crc >> 1;
            }
        }
    }
    return crc;
}
```
