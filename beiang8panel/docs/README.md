## 5. 当前母版要点

- 一个配置对应一个独立进程；一个进程独占一路 TTY 并明确选择一个通信调度器。
- Modbus 主站按 250ms 通信间隔、50ms 响应超时和首次加一次重试执行；写队列优先。
- 采集通信与协议处理分离；HTTP 读取只复制内存快照。
- 写入成功后精确回读同一起点、同一数量的数据，再发布实际状态。
- 任意真实 Modbus 读写成功都会重新开始 30 秒单调计时；达到 30 秒无成功通信时 `dataFresh=false`，保留最后有效值。
- 本机设备线程与 TTY 分离；天气/IP 等网络服务后续继续收口为独立线程和缓存。
