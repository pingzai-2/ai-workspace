# Golden 测试判定规范

## 固定分辨率

- 8 寸工程固定使用 `1920×1200`、DPR `1`。
- Figma 冻结图位于 `test/goldens/`，只读；Flutter 实现快照位于
  `test/generated/8cun/$name.png`。
- 标准素材和实现快照分开保存，不把运行截图写回 `test/goldens/`。

## 动态素材的判定

主页 PM2.5、天气及弹窗后的实时背景可能使用 GIF。GIF 在测试等待、预加载和运行过程中可能处于
不同帧，因此不能把参考截图中的某一帧当作唯一正确结果。脱离参考帧但仍保持页面结构、前景
控件和字体规格的结果，仍然是正确结果。

动态页面统一采用以下规则：

1. 运行时继续使用动态素材，不为了通过 Golden 替换为静态 PNG。
2. 测试保留整张当前帧截图到 `/tmp`，用于人工复核；整张图可以直接查看，但不锁死动态背景。
3. 动态页面的背景、前景数值、状态、按压态和动效都允许随时变化；不把动态前景或动态背景
   的某一帧作为像素契约。
4. 自动测试改验页面尺寸、关键控件存在、关键控件位置/尺寸和交互结果；需要整张当前帧时
   保存到 `/tmp` 供人工确认。局部截图和整张截图都可以生成，但动态页面均不以单帧像素作为通过条件。
5. `1%` 规则只用于真正静态页面或明确标注为静态的局部区域：稳定区域按通道容差 `2` 比较，
   异常像素占已检查像素不超过 `1%` 即通过。

静态页面仍使用完整 `matchesGoldenFile` 像素 Golden。更新 Golden 时只在前景设计确实变化
后更新 `test/generated/8cun/`，不能用动态背景、动态前景或 GIF 的偶然帧变化作为更新理由。

## 验证命令

```sh
flutter test --no-pub test/visual_goldens.dart
flutter test --no-pub --dart-define=RUN_IMPLEMENTATION_GOLDENS=true test/visual_goldens.dart
flutter test --no-pub --update-goldens test/visual_goldens.dart
```

- 视觉脚本没有使用 `_test.dart` 后缀，普通 `flutter test --no-pub` 不会自动执行这份脚本，
  也不会因为它额外启动首页或读取 PNG。首页自身或整机流程测试确实需要首页时不受影响。
- 测试必须从首页进入时，首页只作为导航入口；除首页测试外，不检查首页截图，也不添加与
  目标页面无关的首页断言。
- 第一条明确启动视觉页面并检查页面、按钮和数据，但不读取 PNG。
- 第二条读取 `test/generated/8cun/` 中已经人工确认的实现快照并执行截图比对。
- 第三条重新生成候选实现快照，生成后仍需人工对照 Figma。

8 寸动态页面若新增局部判定，沿用本规范的结构/位置/交互检查方式；需要留档的完整当前帧
写入 `/tmp`，不得写入 `test/goldens/`。
